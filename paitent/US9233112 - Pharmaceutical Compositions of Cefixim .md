# Functional knowledge extracted from the patent

These are the excipient classes explicitly defined in the specification.

| Excipient Class | Functional Role | Examples given in the patent |
| --- | --- | --- |
| Diluents | Increase bulk; may also function as sweeteners | Sucrose (preferred), sorbitol, xylitol, dextrose, fructose, maltitol, etc. |
| Sweeteners | Impart sweetness | Fructose, glucose, sucrose, mannitol, sorbitol, sodium saccharin, sodium cyclamate, aspartame. |
| Viscosity enhancers | Increase liquid viscosity to keep the API suspended for accurate dosing | Xanthan gum (preferred), guar gum, acacia, HPMC, HPC, etc. |
| Dispersing agents | Disperse the API in the suspension | Colloidal silicon dioxide and surfactants. |
| Flavoring agents | Add flavor | Strawberry (preferred), banana, cream flavor. |
| Preservatives | Protect against antimicrobial growth | Sodium benzoate (preferred), benzoic acid, potassium sorbate, parabens, etc. |
